# 서울 아파트 1년 뒤 올랐을까 — AI 두뇌 만들기 실전

AI CITY BUILDERS 강의 기반 서울 아파트 실거래가 예측 및 딥러닝/머신러닝 실험 레포지토리입니다.

## 📌 프로젝트 개요
- **목표**: 2024년 서울 아파트 실거래가 데이터를 바탕으로, 2025년에 5% 이상 상승(`올랐나`: 1 또는 0)할지 여부를 예측하는 분류 모델 개발
- **데이터셋**:
  - 학습 데이터 (`seoul_apt_train.csv`): 3,000건 (정답 레이블 포함)
  - 시험 데이터 (`seoul_apt_test.csv`): 418건 (예측 대상)

## 📁 파일 구조
- `seoul_apt_train.csv`: 학습 데이터셋
- `seoul_apt_test.csv`: 테스트 데이터셋
- `experiment.py`: 기본 피처 엔지니어링 및 교차 검증 스크립트
- `deep_experiment.py`: 심층 피처 엔지니어링 및 앙상블 (CatBoost, HistGBDT, LogReg 등) 스크립트

## 🚀 점수 향상 핵심 전략
1. **피처 엔지니어링**:
   - `평당가`: 가장 강력한 단일 예측 변수
   - `평당가 - 동평당가`, `평당가 / 구평당가`: 지역 내 상대적 가격 차이 및 저평가/고평가 지표
   - `입지 등급` 및 `직전변동` 결측치 보정
2. **모델링 및 앙상블**:
   - 트리 기반 모델 (CatBoost, HistGradientBoosting)과 로지스틱 회귀의 Out-of-fold 블렌딩
   - 최적 결정 임계값(Threshold) 탐색
